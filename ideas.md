# Shiptivitas – Three Actionable Feature Ideas

## 1. Card Activity Timeline

**Hypothesis:** Users may benefit from having visibility into the history of changes made to each card.

**Expected Impact:** Improved transparency, accountability, and easier tracking of task progress.

**What the feature is:** Add an activity timeline to every card, displaying previous status changes, timestamps, and the user responsible for each change.

## 2. Smart Task Reminders

**Hypothesis:** Tasks that remain in the same status for an extended period may need additional attention.

**Expected Impact:** Fewer forgotten tasks and improved task completion rates.

**What the feature is:** Introduce optional reminders for cards that have not changed status within a user-defined period.

## 3. Board Activity Dashboard

**Hypothesis:** Users may benefit from a consolidated view of activity and task progress across their boards.

**Expected Impact:** Easier identification of bottlenecks, better prioritization, and improved visibility into workflow progress.

**What the feature is:** Create a dashboard displaying the number of cards in each status, recent status changes, and cards that have remained inactive for an extended period.

---

*Note: These are proposed product hypotheses based on the available activity data, not verified customer feedback.*
